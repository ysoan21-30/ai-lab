# AI Lab

A collection of AI projects.

## Projects

### [`fraudbot/`](./fraudbot)
A RAG-based chat assistant with document ingestion, vector search (Voyage AI embeddings), and Claude-powered answer generation with source citations. Built with Streamlit.

### [`multi-model-agent/`](./multi-model-agent)
A CLI and web-based agent that routes tasks across multiple LLM providers, with tool integrations for calculations, web search, scraping, data science, and RAG.

### [`ai-data-profiler/`](./ai-data-profiler)
A full-stack SaaS app (FastAPI + Next.js) for automated dataset quality profiling and ML-readiness scoring, with team workspaces, scheduled analysis, custom quality rules, database connectors, webhooks, and audit trails.

## Structure

Each project is self-contained in its own subfolder with its own dependencies, tests, and README. See each project's folder for setup instructions.
